# Scientific C Algorithms

High-performance scientific, numerical, and systems algorithms implemented in pure, portable ISO C99/C11.

## Modules
- `continued_fractions`: Generalized continued fraction approximants
- `pade_approximants`: Rational polynomial approximations
- `chebyshev_collocation`: Chebyshev-Gauss-Lobatto spectral nodes
- `fibonacci_matrix_power`: Matrix recurrences and generalized sequence generation
- `spherical_harmonics_terms`: Associated Legendre polynomials and spherical basis functions

## Requirements
- GCC or Clang (`make test` or `gcc -std=c11 -O3`)
