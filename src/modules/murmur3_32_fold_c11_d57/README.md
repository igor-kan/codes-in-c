# MurmurHash3 32-Bit Block Mix & fmix32 Avalanche (`murmur3_32_fold_c11_d57`)

> Category: **Hashing Primitives** | Language: **C11**

## Overview

Implements Austin Appleby's MurmurHash3_x86_32 with little-endian 4-byte blocks, tail shift assembly, and bijective finalization.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- Distinct seeds or single-bit message changes yield distinct non-trivial 32-bit digests.
