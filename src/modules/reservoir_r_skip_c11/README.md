# Reservoir Algorithm-R Deterministic Stream Sampler (`reservoir_r_skip_c11`)

> Category: **Randomized Sampling** | Language: **C11**

## Overview

Selects K unbiased distinct indices from an online N-item stream using a deterministic 64-bit SplitMix PRNG seed for reproducible reservoir sketches.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(K)` |

## Mathematical & Safety Invariants

- All K reservoir entries remain strictly distinct valid stream indices in [0, N-1].
