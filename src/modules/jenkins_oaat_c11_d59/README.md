# Jenkins One-at-a-Time 32-Bit Hash & Avalanche (`jenkins_oaat_c11_d59`)

> Category: **Non-Cryptographic Hashing** | Language: **C11**

## Overview

Computes Bob Jenkins' canonical One-at-a-Time 32-bit hash with shift-add mixing steps and strong bit avalanche finalization.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- Distinct adjacent byte permutations produce strongly distinct 32-bit digests.
