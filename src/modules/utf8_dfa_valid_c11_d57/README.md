# Strict UTF-8 Codepoint Validator & Overlong Rejector (`utf8_dfa_valid_c11_d57`)

> Category: **Text Validation** | Language: **C11**

## Overview

Validates UTF-8 byte streams against truncated sequences, invalid continuation bytes, UTF-16 surrogates (U+D800..U+DFFF), >U+10FFFF, and overlong encodings.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- Valid ASCII and multi-byte sequences return exact scalar count while overlongs fail cleanly.
