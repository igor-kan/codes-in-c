# Monotonic Time-Series Delta-of-Delta Frame Codec (`delta_zig_frame_c11_d57`)

> Category: **Time-Series Encoding** | Language: **C11**

## Overview

Encodes monotonic or piecewise-smooth int64 series via signed ZigZag second-order deltas and reconstructs original sequences losslessly.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- Encode -> decode recovers every timestamp sequence element-for-element.
