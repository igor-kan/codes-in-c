# COBS Zero-Free Packet Framing Codec (`cobs_framing_codec_c11`)

> Category: **Wire Framing** | Language: **C11**

## Overview

Encodes arbitrary payloads into strictly non-zero byte streams using Consistent Overhead Byte Stuffing and decodes them with length/zero verification.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- Every emitted byte in COBS output is strictly non-zero and round-trips losslessly.
