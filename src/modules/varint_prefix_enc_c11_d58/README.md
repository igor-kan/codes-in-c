# Prefix-Length Self-Delimiting Varint Codec (`varint_prefix_enc_c11_d58`)

> Category: **Binary Formats** | Language: **C11**

## Overview

Encodes uint64 values with first-byte unary tag-length counts for single-branch header decoding cleanly.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(1)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- Values < 128 fit in 1 byte and full uint64 values roundtrip identically.
