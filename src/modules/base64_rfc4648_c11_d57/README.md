# RFC 4648 Base64 Standard Codec (`base64_rfc4648_c11_d57`)

> Category: **Binary Encoding** | Language: **C11**

## Overview

Encodes raw byte octets into RFC 4648 6-bit Base64 ASCII characters with '=' padding and decodes cleanly with strict alphabet validation.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- RFC 4648 test vectors ('f', 'fo', 'foo', 'foobar') encode and decode losslessly.
