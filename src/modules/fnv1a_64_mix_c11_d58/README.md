# Streaming FNV-1a 64-Bit Incremental Hash Digester (`fnv1a_64_mix_c11_d58`)

> Category: **Streaming Hashing** | Language: **C11**

## Overview

Maintains incremental FNV-1a 64-bit state (offset basis 0xcbf29ce484222325, prime 0x100000001b3) supporting chunked streaming identical to single-buffer hashing.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- Splitting a message across two arbitrary chunks equals single-shot hashing identically.
