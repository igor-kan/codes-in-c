# Unicode Scalar <-> UTF-16 Surrogate Pair Codec (`utf16_surrogate_c11_d59`)

> Category: **Unicode Codecs** | Language: **C11**

## Overview

Encodes supplementary plane codepoints (U+10000..U+10FFFF) into high/low UTF-16 surrogate pairs and rejects unpaired surrogates strictly.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(1)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- All supplementary codepoints roundtrip identically through UTF-16 pair encoding.
