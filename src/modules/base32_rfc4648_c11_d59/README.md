# RFC 4648 5-Bit Base32 Binary-to-Text Codec (`base32_rfc4648_c11_d59`)

> Category: **Binary Encoding** | Language: **C11**

## Overview

Encodes raw octets in 5-bit Base32 blocks with '=' padding cleanly verifying RFC 4648 test vectors and full lossless roundtrips.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- RFC 4648 'foob' vector encodes cleanly to 'MZXW6YQ=' and decodes losslessly.
